# 唯品会（vip）账单整理 · 平台技能文档

> 适配器：`core/platforms/vip.py`（承接 bill_arr.wph_arr ≈987 行，B2B 口径）。
> 总体方法论见 bill-methodology.md。唯品会是**按旬出账 + 多店一簿 + 不做日期过滤**
> 的特例平台，与其余平台差异最大。

## 1. 数据源：按旬目录，多文件族

- **一个账单月 = 三旬**（2026-11-16 用户确认）：如 8 月账期平台给三份账单
  （原始是三个 zip），实际结算期 2026.07.22-07.31 / 08.01-08.10 / 08.11-08.21，
  基本每月如此（上月下旬+本月上中旬）。目录/zip 名即结算期。
- **给父目录或整批旬 zip 即可**：pipeline._vip_expand_xuns 自动识别旬结构
  （旬名目录 / 旬名 zip / 父目录下混合），逐旬跑并聚合终态；也可单给一旬。
  s_date/e_date 只用于生成账期标签，**不做行级日期过滤**（文件已按旬切好，原脚本口径）。
- 文件族按文件名前缀识别，各族读各自 sheet 集合（缺 sheet 跳过）：

| 族 | 识别 | sheet 集合 |
|---|---|---|
| VIP- | 文件名含 `VIP-` | 销售明细/客退明细/活动折扣明细/活动折扣明细_2/会员价保/其他明细/差异详情 |
| TGCY- | 含 `TGCY-` | 其他明细/差异详情 |
| ZS- | 含 `ZS-` | 销售明细/客退明细/活动折扣明细/差异详情 |
| MD- | 含 `MD-` 且不含 PRSHOP | 采购入库明细/采购退供明细 |
| PRSHOP-MD | 含 `PRSHOP-MD` | 同 MD |
| -H- | 含 `-H-` | 差异详情（数量/明细金额列，税率不 round） |
| VIPSHOP- | 含 `VIPSHOP-` | 销售明细/客退明细 |

- 单文件可达 70MB（销售明细几十万行），解析+导出耗时数分钟属正常；
  回归建议后台跑并落日志，勿在交互超时里硬等。
- ⚠️ 采购退供明细列名带**前导空格**（` 退货数量`/` 条码`），上游原样，勿 strip 列名。

## 2. 口径要点

- **全部行业务类别=货款**（B2B 结算口径，没有费用分类链）。
- 金额：含税结算金额>0→收款，<0→退款取正；不含税 = 含税/(1+税率)。
  ⚠️ **舍入顺序**：折扣/价保/差异类先把含税金额 round(2) 再除税再 round(2)
  （原脚本 4101-4102 行）；用未舍入值除税会漂移（vip2 实证差 0.14 元，已修）。
  H 表税率**不 round**（4714 行），与其余 sheet 不同，保持。
- 数量先 abs；退款>0 且数量>0 时取负。
- 品牌：先按品牌名称 BRAND_DICT 映射，再按**款号前缀规则覆盖**（顺序敏感）：
  8+字母→FR / 42+数字→MyALL / 7开头→MyAll(菁禾) / 3开头→YUUSAAY / 5+数字→C3。
- 店铺由品牌反推 SHOP_BY_BRAND：QS→VIP00101 / CO→VIP00201 / FR / MyALL /
  MyAll(菁禾) / YUUSAAY / C3；未知→唯品会_未知店铺。**多店一簿**，透视按店铺分组。

## 3. 交付物（两层目录特例，2026-11-16 用户需求）

- 第一层批次目录：`YYYY-MM-唯品会-唯品中国`（供应商默认唯品中国，不写店铺）；
- 第二层旬交付文件：`唯品会_{带日账期}唯品中国_账单整理.xlsx`，如
  `唯品会_2026年0801-2026年0810唯品中国_账单整理.xlsx`——三旬文件在同目录**累积**
  （跑第二旬不删第一旬；重跑同旬同名覆盖）。底稿按旬子目录隔离
  （底稿/2026年0801-2026年0810/…）。
- 三 sheet：氚云导入模板 / 唯品会透视 / 唯品会账单整理（16 列，含税率/含税/不含税/PO）。
- 基准布局参照：氚云导入成功\唯品会\ 下三个旬文件。

## 4. 漂移应对速查

| 症状 | 先查 | 修法 |
|---|---|---|
| 某族数据整块消失 | 文件名前缀变化（族识别失配） | diff 文件名；扩 by() 前缀规则 |
| 某 sheet 金额消失 | sheet 改名（缺 sheet 静默跳过） | diff sheet 名清单 |
| 「未知店铺」金额增大 | 新品牌/款号前缀规则未覆盖 | 引导人类确认品牌归属，扩 BRAND_DICT/前缀规则（代码级+回归） |
| 不含税合计分级漂移 | 舍入顺序被改（先除税后 round） | 恢复「含税先 round(2) 再除税」；H 表税率不 round |
| 缺列报错 | 结算列长列名变化（`结算含税金额:销售数量*结算含税单价`） | 同步 _SETTLE_TAX/_SETTLE_NOTAX |
| 数量符号异常 | 退款判定与 abs 顺序 | 保持先 abs 后按退款取负 |

基准回归锚点：三旬全量（2026.07.22-07.31 / 08.01-08.10 / 08.11-08.21），
vip2 289895 行逐 sheet 对平；vip1/vip3 同法验证（大文件后台跑）。
