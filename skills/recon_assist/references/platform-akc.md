# 爱库存（akc）账单整理 · 平台技能文档

> 适配器：`core/platforms/akc.py`（承接 bill_arr.akc_arr ≈748 行）。
> 总体方法论见 bill-methodology.md。

## 1. 数据源：单文件多店多 sheet（与其它平台差异最大之一）

- 单个 xlsx（文件名如 `20260901111824767-0.xlsx`），**13 个费用 sheet**：
  订单货款/售后扣款/营销费用/退换运费无忧/订单赔付/违规明细/申诉补款/商家直客/
  基础技术年费/品牌推广费/交易手续费/流量雷达服务费/二程快递费。
- **缺 sheet 跳过；出现未知 sheet 直接报错**（ALLOWED_SHEETS 白名单）——
  上游新增费用 sheet 是显式漂移信号，需扩展白名单与归一逻辑（代码级+回归）。
- **一个文件含多家店铺**：按「店铺ID」映射（SHOP_BY_ID）：
  S18770776023311001→AKC003 秋水伊人QS / S187707760→AKC004 可可尼CO；
  未知 ID 回落 AKC003。品牌推广费/交易手续费/流量雷达/二程快递/基础技术年费
  无店铺ID（置空后走回落）。透视按 店铺名称+店铺编码+业务类别 分组（多店一簿）。
- 账期过滤用「账单日」→资金日期。

## 2. 各 sheet 归一口径（金额列/订单列/方向各不同）

| sheet | 金额列 | 方向 | 订单列 | 业务类别 |
|---|---|---|---|---|
| 订单货款 | 结算金额 | 全部收款 | 二级订单号 | 货款 |
| 售后扣款 | 扣款金额 | 全部退款 | 二级订单号 | 结算科目=售后退货款→**货款**，否则售后扣款 |
| 营销费用 | 商家承担总金额 | 收付类型（商家应收/应付） | 二级订单号 | 营销费用 |
| 退换运费无忧/订单赔付/违规明细/交易手续费 | 扣款金额 | 收付类型 | 二级订单号/二级单号 | 同名 |
| 申诉补款 | 补款金额 | 收付类型 | 二级单号 | 申诉补款 |
| 商家直客/品牌推广费 | 结算金额 | 收付类型 | 订单号/二级单号 | 同名 |
| 基础技术年费 | 结算金额 | 收付类型 | 无 | 基础技术年费 |
| 流量雷达服务费 | 扣款金额 | 收付类型 | 无 | 流量雷达服务费 |
| 二程快递费 | 结算金额 | 收付类型 | 无 | **快递费** |

⚠️ 商家直客的时间列是「**进线时间**」（不是业务发生时间）。

## 3. 款号口径（去数据库依赖的有意改进）

原脚本查 ADB AI_product_info 补款号；8 月基准实证 **款号 == sku[:-5]**
（sku=625253M01066101401 → 款号=625253M010661），插件按此推导，不连数据库。
sku 为空则款号为空、品牌置空。若未来 sku 编码规则变化（尾 5 位不再是颜色码），
此推导会错——发现款号异常先 diff sku 结构。

## 4. 交付物（目录与文件名特例）

- 批次目录：`YYYY-MM-爱库存`（2026-11-16 用户需求：**不写店铺段**——一个爱库存
  渠道含多个实际店铺 AKC003/AKC004，店铺映射表里有）；重跑覆盖。
- 交付文件：`爱库存_{账期}_账单整理.xlsx`——**不含店铺名/编码**（多店一簿，原脚本口径；
  pipeline 用 book.file_name 特例支持）。三 sheet：氚云导入模板 / 爱库存透视 /
  爱库存账单整理（14 列：数据来源/店铺名称/店铺ID/店铺编码/销售订单号/业务发生时间/
  资金日期/业务类别/收款/退款/sku/款号/品牌/数量）。

## 5. 漂移应对速查

| 症状 | 先查 | 修法 |
|---|---|---|
| 「包含未知工作表」 | 上游新增费用 sheet（报错带 unknown_sheets） | 人类确认口径后扩 ALLOWED_SHEETS + 归一段（代码级+回归） |
| 某类金额消失 | 对应 sheet 改名/缺失（缺 sheet 静默跳过） | diff sheet 名清单 |
| 店铺归属错 | 新店铺ID 未进 SHOP_BY_ID（回落 AKC003） | 补映射（代码级）；引导人类确认新店编码 |
| 款号异常 | sku 编码规则变化 | 核对 sku[:-5] 推导，必要时恢复查库口径 |
| 售后扣款/货款比例跳变 | 结算科目新值 | 售后退货款判定条件核对 |

基准回归锚点：AKC003 目录 2026-08（43305 行，含 AKC003+AKC004 两店，逐 sheet 对平）。
