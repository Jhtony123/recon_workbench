# 抖音（douyin）账单整理 · 平台技能文档

> 适配器：`core/platforms/douyin.py`（承接 bill_arr.dy_arr ≈283 行）。
> 总体方法论见 bill-methodology.md。

## 1. 数据源

- file_paths 目录下 `*.csv`（资金账单明细，utf-8 系）；订单号/子订单号/售后编号/商品ID/备注 强制 str。
- 必需列：动账时间 / 订单号 / 动账方向 / 动账金额 / 订单退款 / 备注。
- ID 列带 Excel 文本保护前缀（单引号 `'` 或 `\t`），清洗剥离开头引号/制表符。
  ⚠️ 历史坑：只切 `\t` 会把单引号留下 → 订单号撞不上 OMS → 整店匹配 0 行。
  上游若换保护符（如改成 `="..."`），需扩展剥离正则。
- **账期过滤用「动账时间」**（不是下单时间）。
- 可选列缺失自动补 0/空（OPTIONAL_NUMERIC_COLUMNS / OPTIONAL_TEXT_COLUMNS）——
  旧账单可跑；**但新增列若带金额，不会自动参与公式**（见 §3）。

## 2. 分类机制：组件列展开（不是打标签！）

抖音**没有编码字典**，一行原始账单按金额组件展开成多行标准账单：

```
销售货款 = 货款应结 + 订单实付应结 + 实际平台补贴_运费 + 实际平台补贴
         + 实际达人补贴 + 实际抖音支付补贴 + 实际抖音月付营销补贴
         + 以旧换新抵扣 + 银行补贴 + 政府补贴平台垫资          ← SALES_COMPONENTS（10项）
销售退款 = 订单退款（特殊备注按动账方向取动账金额；销售货款<0 时转退款）
平台费用 = 平台服务费 + 渠道分成 + 招商服务费 + 站外推广费 + 其他分成
平台佣金 = 佣金 + 服务商佣金
罚款/小额打款/保证金/提现/运费险/货款扣罚服务费 ← 备注关键字命中取 ±动账金额
账扣费用 = ±动账金额 - |以上小计|（兜底桶）
```

汇总 sheet 固定 10 类：货款 / 平台服务费 / 运费险 / 货款扣罚服务费 / 账扣费用 /
佣金 / 罚款 / 小额打款 / 保证金 / 提现（全 0 类删除）。

备注关键字（各自有排除项，改词必须回归）：
- 罚款：含「赔付」且不含「普通退款转赔付」「发货超时」，或含「催发」「发票补偿金」
- 小额打款：含「小额打款」且不含「普通退款转赔付」「打款,订单号」
- 保证金/提现：同名子串；运费险：「保费扣除」；货款扣罚服务费：「发货超时」
- 特殊：备注含「普通退款转赔付」或「打款,订单号」→ 销售退款按动账方向取动账金额

## 3. 金额自检门：「金额差异」列

明细 48 列里 `金额差异 = 动账金额 - (小计 + 账扣费用)`，**应恒 0**。
由于账扣费用是兜底桶，新费用**不会让门报错，而是悄悄进「账扣费用」**——
这是抖音漂移的隐蔽形态：账扣费用金额异常增大 = 有新组件列/新话术没被识别。

**每月必查**：汇总里「账扣费用」占比 vs 上月；异常增大 →
读明细筛 账扣费用≠0 的行，看备注与新增列，判断：
- 上游新增补贴/费用列（如新的「实际XX补贴」）→ 应加入 SALES_COMPONENTS 或
  PLATFORM_FEE_COMPONENTS（代码级，需人类确认口径 + 回归）；
- 新备注话术 → 补关键字分支（代码级 + 回归）。
抖音组件公式**不走规则表**（biz_code 规则对抖音无效），改动都在
`douyin.py` 常量元组里，改后必须跑基准回归。

## 4. 交付物

`抖音_抖音_{店名}_{编码}_{账期}_账单整理.xlsx` 三 sheet：
- 氚云导入模板（4 列）
- 汇总（8 列透视，10 类中非零者）
- 抖音账单（**48 列**明细；「佣金」列源数据本就重名两次，保持原样不去重——
  财务逐列对照时列数必须对得上）

## 5. 漂移应对速查

| 症状 | 先查 | 修法 |
|---|---|---|
| 「缺少字段」 | 必需 6 列改名 | 改 REQUIRED_COLUMNS（代码级+回归） |
| 订单号匹配不上 OMS | ID 前缀保护符变化 | 扩展 clean() 剥离正则 |
| 账扣费用异常增大 | 新组件列 / 新备注话术（§3） | 人类确认口径后改常量元组/关键字 |
| 货款金额与上月口径跳变 | 补贴列增减（SALES_COMPONENTS） | diff 新旧账单列头，确认新列归属 |
| 汇总类别金额镜像 | 关键字排除项失效（话术微调） | 对照备注原文修分支 |
| 明细列数 ≠ 48 | 上游增删列 | DETAIL_COLUMNS 同步（保持重名佣金），回归 |

DY014 为组件口径校验店（销售货款 1800.26 / 平台费用 -60.81 / 货款扣罚 -10 / 提现 -10000）。
