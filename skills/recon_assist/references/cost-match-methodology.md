## 0. 业务定位

财务每月在**金蝶 ERP** 完成成本核算后，提供独立的物料成本表。本阶段把表中的
**实际成本单价**回填到 SKU 匹配表的每一行（采购单价/发货成本），并重算透视毛利，
产出「成本匹配」版结果表。会计意义：SKU 对账阶段用**标准成本**（吊牌体系）估毛利，
本阶段换成**当月实际加权成本**，毛利才是财务可入账口径。

两条成本线**来源不同、不得互相覆盖**（2026-08 基准逐行验证 300/300）：
- **标准成本单价** ← ADB `AI_product_info.standard_cost`（SKU 对账阶段已写入），本阶段不动；
- **采购单价** ← 财务成本表，按**款号（SPU）**查。

## 1. 成本表结构（物料成本_YYYYMM.xlsx，实测 202610）

- sheet：`仓库编码`（CK001… 仓库→品牌映射，**cost_match 不消费**）+ `1月末`…`12月末` 按月一个 sheet。
- **必须按账期选 sheet**（10 月 → `10月末`）。影刀靠弹窗手填；不指定时 pandas 默认读
  第一个 sheet（`1月末`），采购单价全线偏低（2026-11-13 实测踩坑）。
- 列：`物料编码 / 物料名称 / 规格型号 / 数量 / 单价`（尾部可能有空列）。
  - ⚠️ **`物料编码` 列实测只有品牌值 CO/QS/C3**（或空），不是 SKU 也不是款号；
    `物料名称` 实测是 '9' 之类占位。**真正的款号在 `规格型号` 列**（13 位，如 925308C050001）。
  - `数量` 列全空；`单价` = **不含税**实际加权成本，高精度小数（10月末 13623 行，
    小数普遍超 2 位，如 127.761061946903；范围 1~3761 元）。
  - 10月末 37899 行中 24276 行**整行全空**（表格拖拽残留），有效行 13623，规格型号唯一无重复。
- **颗粒度 = SPU（款号）**：财务成本核算到款号即可，同款所有 SKU 共用一个单价。
  影刀 `cost_base` 有两个分支（弹窗选择）：
  - `成本价按sku计算`：`dict(zip(物料编码, 单价))` —— 本表结构下必然全不命中，**实际不用**；
  - `成本价按款号计算`：`drop_duplicates('规格型号')` → `dict(zip(规格型号, 单价))` —— **实际口径**。
  - 单价 `fillna(0.00).astype(float)`；物料编码/规格型号强制 str 读入。

## 2. 明细回填（cost_match L67-172，收/退款两侧对称）

输入 = SKU 匹配表的 `收款匹配` / `退款匹配` sheet（31 列）。逐侧：

1. `数量 = abs(to_numeric(数量).fillna(0))` —— **取绝对值**（退款侧数量本为负）。
2. `采购单价 = 款号 → cost_base_dict.get(x)`，未命中 `fillna(0.00)`。
   ⚠️ **本阶段无 NaN 语义**：SKU 对账阶段账单行采购单价是空白，成本匹配阶段
   **全部 fillna(0)**（HYK 基准实测：SKU 阶段 177 行空白 → 成本阶段全有值或 0）。
3. `发货成本 = round(数量 × 采购单价, 2)` —— **元域乘完再 round**（L81/L137）。
   ⚠️ 不得「单价先量化到分再乘数量」：10月末 13623 行单价小数超 2 位，
   先量化会累积 ±1 分差（插件 core/cost.py `_round_ship` 用 Decimal 原始精度复刻）。
4. `结算金额 fillna(0).astype(float)`。⚠️ **货款金额不 fillna**：补录/秒退未命中行
   基准是空白单元格（2026-11-18 单元格级实测：HYK 收 11/退 16、KS001 7、DY020 3），
   空值保持空白（合计不变，但空态须与基准一致；pandas 读表会把空白读成 NaN，
   判空必须用 isna 而非 is None）。
5. **占位符重写**（与 SKU 阶段不同！）：
   - `款号`：`str.replace("None","无款号")` + `fillna("无款号")`
     （SKU 阶段秒退/未匹配行款号是字面串 "None" 或空白 → 本阶段统一「无款号」）；
   - `吊牌价`：`astype(str).str.replace("None","无吊牌价")` + `fillna("无吊牌价")`；
   - `商品名称/季节/年份` fillna「无商品名称/无季节/无年份」；`品牌` fillna「未知」。
   - HYK 基准实测：47 行秒退行 SKU 阶段款号="None"/吊牌价="None" → 成本阶段「无款号/无吊牌价」。
6. **唯品会 FR 特例**（L94-98/L150-154）：`店铺名称 contains '唯品会' & 品牌=='FR'` →
   `发货成本 = 标准成本`（FR 标准成本在 SKU 阶段已被覆盖为结算金额，代销口径）。
   VIP 10月上旬基准实测：FR 62044 行全部 发货成本=标准成本、采购单价=0；
   非 FR 82276 行正常查成本表。**爱库存无此特例**（AKC 3727 行全查表）。
7. 已知源码笔误 L147：退款段误写 `df_receipt['吊牌价'].fillna(...)`（应为 df_pay）——
   退款侧吊牌价占位实际靠 L140 的 str.replace 兜住 "None"，纯 NaN 行漏填；迁移时按意图修正并登记。

## 3. 透视重算（与 SKU 对账阶段口径**完全不同**）

### 3.1 匹配透视（df_pivot，L100-175）
- 收/退款各自按 `店铺名称/款号/处理意见/品类/年份/季节/品牌/吊牌价` 透视，
  values=`数量/货款分摊金额/结算金额/发货成本/标准成本` sum。
- 收款侧数量 abs；**退款侧五个 value 全取负**；`数据来源`='收款匹配'/'退款匹配'。
- 列序 unicolumns **14 列，无店铺编码**（SKU 阶段是 15 列含店铺编码——两阶段列集不同！）。

### 3.2 款号/店铺透视（L184-617）
- 结构同 SKU 阶段：收款段处理意见=「结转成本」、退款段=「冲成本/冲发出商品」；
  金额先按全部行聚合（货款分摊/标准成本），成本/数量/结算只按意见过滤后回填；
  冲发出商品数量/金额单列（退款侧「冲发出商品」意见行）。
- **毛利口径换成本**（SKU 阶段扣标准成本、不除税；本阶段扣**发货成本**）：
  - `is_include_tax=="是"`：毛利 = 货款分摊金额 − 发货成本；率 = 毛利/货款分摊金额 round(4)；
  - **不含税（10 月实际口径）**：毛利 = round(货款分摊金额 **/1.13** − 发货成本, 2)；
    率 = round(毛利 / (货款分摊金额/1.13), 4)。订单结算口径同理换订单结算金额。
  - HYK 基准验证：44510/1.13 − 17889.54 = 21499.84 ✓（10 月 is_include_tax=否）。
  - 收入为 0 → 率 0（np.where）。
- 删行规则：收款款号透视删「货款分摊金额==0」行；退款款号透视删
  「发货成本==0 & 货款分摊==0 & 订单结算==0」行。
- **列集**：店铺透视 **13 列**、款号透视 **18 列**——均**无店铺编码**
  （SKU 阶段 14/19 列含店铺编码；cost_match 的 shop_pivot_col/product_pivot_col 本就没有）。
- 冲发出商品数量：cost_match 版**没有** look_sku L1804-1805 的链式赋值笔误，数量是真数量
  （HYK 成本阶段基准仅 2 行非零：-1/-1，对应金额 -38.99/-87.61）。

### 3.3 输出（L629-635）
同名文件写入输入目录下的 `成本匹配/` 子目录，6 sheet：
店铺数据透视(13) / 款号数据透视(18) / 匹配透视(14) / 收款匹配(31) / 退款匹配(31) / 已匹配的巨益单号(3，原样透传)。
明细 31 列列头与 SKU 阶段完全一致（采购单价/发货成本从空/0 变为有值）。

## 5b. 用户确认决策（2026-11-18，spec 依据）

1. **状态机**：成本匹配成功后批次从 `未匹配成本/` **迁移**到 `已匹配成本/`（失败留守）。
2. **税口径（源码复核确认）**：货款含税、标准成本（DB 吊牌体系）含税、成本表单价不含税。
   SKU 阶段毛利=含税收入−含税标准成本（配对，不除税）；成本阶段毛利=收入/1.13−不含税发货成本
   （配对）。**/1.13 只作用于收入侧**（货款分摊金额/订单结算金额），标准成本/采购单价/发货成本
   全程不除税。税率 1.13 固定常量（财务特殊说明才改）；is_include_tax 开关保留默认关。
3. **成本表格式固定**：`物料成本_YYYYMM.xlsx` + `{月}月末` sheet + 规格型号=SPU 键。
   财务若给异形表，先**转换成该固定格式**再进流程（转换层独立，不改核心取价逻辑）。
4. **范围含唯品会/爱库存**：VIP 需先补跑 SKU 对账（多旬）再做成本匹配。
5. **占位符/列集照影刀基准**（§2.5 / §3.2）。
6. **成本缺失**：查不到款号 → 采购单价/发货成本填 0（照影刀）；**明细 sheet 末尾新增一列
   「特殊情况说明」**（用户明确要求，第 32 列，属用户批准的基准附加列）：
   取值「无款号」/「成本表无此款」，正常行留空；缺失款号清单同时进运行汇报与底稿。
